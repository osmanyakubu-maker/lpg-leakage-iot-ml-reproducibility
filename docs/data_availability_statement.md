# Data Availability statement

**Data Availability**

The SB112 dataset used for contextual reference is publicly available from Zenodo at
https://doi.org/10.5281/zenodo.6616632 [12]. The analysis code, configuration files, random seeds
and scripts that reproduce the reported tables and figures have been deposited in
https://github.com/osmanyakubu-maker/lpg-leakage-iot-ml-reproducibility, released under the MIT
licence. The simulation dataset, test-chamber experimental logs, trained model artifacts and the
raw CFD outputs are available from the corresponding author on reasonable request. The
human-factors data are available only in de-identified aggregate form, which is included in the
repository, consistent with the ethics approval (GCU/RERC/2026/187), to protect participant
privacy.
